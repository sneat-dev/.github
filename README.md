# Sneat Dev

We build developer tools around [DataTug](https://datatug.app), our flagship
product. [See how we build DataTug with our tools](https://datatug.app/en/under-the-hood/tools-we-built/).

We use [WB](https://sneat.dev/wb) to coordinate repository worktrees, checks,
and delivery across the development fleet. Explore [the WB CLI](https://github.com/sneat-dev/wb)
or [the Workbench site](https://sneat.dev/wb).
